Hỗ trợ Android & iOS

Cài đặt ứng dụng FinSmart VN lên điện thoại Android

Tối ưu chuẩn PWA. Bạn có thể tải file hoặc cài đặt trực tiếp ra màn hình chính Android để dùng toàn màn hình.

Triển khai vĩnh viễn trên GitHub Pages & Đồng bộ Cloud

Lưu trữ ứng dụng miễn phí trên GitHub và kết nối Google Sheets để đồng bộ đa thiết bị.

Các bước đưa lên GitHub Pages:

  1. Bấm nút "Tải file App (.html)" ở bên trên để lấy file code.
  2. Đổi tên tệp thành index.html.
  3. Truy cập GitHub.com, tạo một Repository mới (đặt tên ví dụ: finsmart, chọn Public).
  4. Tải (Upload) file index.html lên kho lưu trữ đó.
  5. Vào phần Settings ➔ Pages, tại mục Branch chọn main và nhấn Save. Bạn sẽ nhận được link web cá nhân vĩnh viễn!

Dữ liệu giao dịch của bạn sẽ được đồng bộ trực tiếp vào file Google Sheets trên Google Drive khi bạn dùng trên cả điện thoại và máy tính.

Hướng dẫn đưa App lên Android

Chọn 1 trong 2 cách đơn giản

Cách 1: Khuyên dùng (Tạo icon ngoài màn hình)
  1. Bấm nút "Tải file App (.html)" bên dưới.
  2. Đưa lên trang miễn phí app.netlify.com/drop để nhận đường link.
  3. Mở link đó bằng Google Chrome trên điện thoại Android.
  4. Bấm 3 chấm (⋮) ở Chrome ➔ Chọn "Thêm vào màn hình chính".
Cách 2: Chạy trực tiếp file
  1. Gửi file index.html qua Zalo hoặc Google Drive sang điện thoại.
  2. Chạm mở file bằng trình duyệt Chrome trên điện thoại.
